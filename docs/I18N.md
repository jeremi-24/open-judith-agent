# Languages: French and English

Judith speaks both. On a first start she takes the language of Windows (French, else English);
the **FR | EN** switch of the welcome window and **Langue / Language** in the tray menu change
it later. Everything follows: the windows, the messages, what Claude answers, the speech
recognition and the fallback voice.

## How a sentence is translated

The **French sentence is the key**. The code and the pages keep their French text, and
`src/core/locales/en.js` says what each sentence is in English.

```js
t('Je réfléchis…')                           // "Thinking…" in English
t('Étape {step}/{max}', { step, max })       // "Step 2/12"
```

In a page (`*.html`), write the French text as usual: `translateDocument()` replaces every text,
`title`, `aria-label`, `placeholder` and `alt` on load.

## Adding a sentence

1. Write it in French (in the code with `t(...)`, or in the page).
2. `node scripts/i18n-keys.mjs` lists the sentences without an English version.
3. Add them to `src/core/locales/en.js`, keeping the `{placeholders}`.

`npm test` fails if a sentence has no English version, if an English entry is left over, if
placeholders differ, or if French letters slipped into an English text.

Do not call `t()` at the top level of a file run by the main process (it runs before the language
is known); in a window it is fine.

## Adding another language

Add a dictionary next to `en.js`, give `LANGUAGES` in `src/core/i18n.js` its code, and give
`speech.js` its Windows voices. Two things are language-specific beyond the text:

- **The voice.** The local voice follows the language: Siwis in French, Kristin in English
  (`LOCAL_VOICE_FOR` in `src/main/models.js`). For any other language the notch uses the Windows voices
  of that language, or a cloud voice (Fish Audio, ElevenLabs).
- **Words that mean "stop" or "on the screen"** (`src/core/turn.js`, `src/core/needs-screen.js`,
  `src/core/hallucinations.js`) already understand French and English together.

The 3D scene frame cannot reach Judith: the board gives it the language in its URL.
